# Demo — Hoja de ruta

Build compilado de una demo, publicado para mostrarlo. **Acá no vive el código fuente**,
que es privado.

Los datos de la demo son **sintéticos**: ningún nombre, monto ni teléfono real de ningún
negocio.

Este directorio se regenera con `npm run build` desde el repositorio privado; no se edita
a mano.
